rag-stack {{ .Chart.Version }} (rag-api {{ .Values.ragApi.image.tag | default .Chart.AppVersion }}) is installed.

On the first start rag-api pulls {{ .Values.ragApi.config.embedModel }} and {{ .Values.ragApi.config.chatModel }} into Ollama.
It is ready when this shows READY 1/1 (can take several minutes):

  kubectl -n {{ .Release.Namespace }} get deploy {{ include "rag-stack.ragApiName" . }}

{{- if .Values.ragApi.auth.enabled }}

API key:

  export RAG_API_KEY=$(kubectl -n {{ .Release.Namespace }} get secret {{ include "rag-stack.apiKeySecretName" . }} -o jsonpath='{.data.{{ .Values.ragApi.auth.secretKey }}}' | base64 -d)
{{- end }}

Try it:

{{- if .Values.ingress.enabled }}
  export RAG_URL=http{{ if .Values.ingress.tls }}s{{ end }}://{{ (index .Values.ingress.hosts 0).host }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "rag-stack.ragApiName" . }} 8000:{{ .Values.ragApi.service.port }}
  export RAG_URL=http://127.0.0.1:8000
{{- end }}

  curl -s -X POST "$RAG_URL/ingest" -H "X-API-Key: $RAG_API_KEY" -F files=@handbook.pdf
  curl -s -X POST "$RAG_URL/query" -H "X-API-Key: $RAG_API_KEY" \
    -H 'Content-Type: application/json' -d '{"question": "What does the handbook say about holidays?"}'
